Roastify Design Bench

Run a whole coffee line without hand-editing one box at a time.

Roastify’s Design Studio lays out beautiful boxes — one at a time, by hand, with no history and no undo. The Design Bench adds the three things a growing catalog needs: version control, bulk AI editing, and a straight line to Shopify.

what changed

An undo button, a bulk editor, and a bridge to your storefront.

01 · versioned
Every design is a git commit.

A design stops being a 2.3 MB opaque blob and becomes a folder in your own private GitHub repo — layout, text, and artwork. Real history, real rollback, real what-if. “What did the Colombia label look like before I changed the roast scale?” now has an answer.

02 · bulk
An AI agent does the tedious pass.

Ask an agent to fetch a set of designs, change the origin line, nudge the roast scale, and keep the type consistent — across the whole line, in one pass. It edits text, geometry, and fills, and commits each one with a real message and a version tag.

03 · synced
It flows through to Shopify.

Paired with Shopify’s own tools, the edited products move out to your storefront — new SKUs and edits alike. Design in one place, ship to the store, done.

how it works

Three actors, one clean division of labor.

The courier

A tiny button that runs inside Roastify on your own login. It does the two steps that need your session: send a product’s design up to the library, and apply a finished design back onto a product. Nothing else touches Roastify’s authenticated screen.

The agent

Your AI assistant, connected to Roastify MCP, reads the catalog and edits a design’s words, layout, and colors — everything between the two courier steps. No pixel-nudging by hand.

The library

A private per-merchant GitHub repo is the store as version control. Browse it in GitHub, diff any change, roll back a bad edit — a design is a readable folder, not a mystery row.

Why a courier at all? Roastify has no public API for design writes — they live behind a browser session. So instead of waiting for an API, the Bench brings its own seam: a userscript, served from this site, that lets your agent work through the page you’re already signed into.

get started

Connect once, then pay only for what you use.

No account to create, no email, no subscription, no KYC. Your identity is a Nostr key (an npub), and you top up a balance in Bitcoin Lightning sats — the agent spends a few as it works.

  1. Open the Design Bench and sign in with your npub.
    New to Nostr? Any Nostr client makes a key in a minute. On the Bench, you’ll hand over your own Roastify API key through an encrypted direct message — it’s vaulted encrypted, and the browser never sees it again.
  2. Top up your balance.
    Fund a few sats over Bitcoin Lightning from the Wallet. You pay per call as the agent works — nothing up front, nothing recurring.
  3. Install the courier on Roastify.
    A one-time button for Mac, iPad, or iPhone. Full instructions are on the design-tools page — it always loads the latest courier, so you never reinstall it.
  4. Point your AI agent at Roastify MCP.
    Connect an MCP-capable assistant to https://roastify-mcp.fastmcp.app/mcp, then just ask: “version these designs, fix the roast scale across the line, and push them back.”
