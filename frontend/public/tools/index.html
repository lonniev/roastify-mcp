roastify · operator tools

Design tools

Two tools that run inside Roastify's Design Studio on your own login — no dev console, works on an iPad. The courier shuttles designs to and from your Design Bench; Push design is a quick direct copy. Both are for your own operator account, separate from the patron Bench.

roastify · courier

Design courier

Shuttles a design between Roastify and your Design Bench library: send a product's design up to edit it in the Bench, then bring the edited design back onto a product. It logs into Roastify MCP with your npub (the standard DM proof) and never edits anything itself — all redesign happens in the Bench.

1 · Install the button (once)

On a Mac: drag this to your bookmarks bar.

➤ Design courier

On iPad: add any page to Favorites, edit that bookmark, and replace its address with the code below.

2 · Use it

  1. Open merchant.roastify.app and sign in.
  2. Tap Design courier. Log in with your npub — reply to the Nostr DM, then confirm.
  3. Send this design → library stashes the selected product's design for the Bench.
  4. Edit it in the Design Bench, then come back and Apply library design → this product to write it onto a product.
Applying overwrites the selected product's design. Its thumbnail keeps the old preview until you open it in the Designer, which re-renders it. Use a throwaway product until you trust it.

roastify · operator tool

Push design

The older direct tool: copies one saved design straight onto another product, with in-panel font repair. Superseded by the courier + Bench flow above, but kept for a quick one-off copy.

1 · Install the button (once)

On a Mac: drag this to your bookmarks bar.

➤ Push design

On iPad: bookmarklets can't be dragged. Easiest path — install it on a Mac signed into the same iCloud, and it syncs to your iPad's bookmarks. Or add any page to Favorites, then edit that bookmark and replace its address with the code below.

2 · Use it

  1. Open merchant.roastify.app and sign in.
  2. Tap the Push design bookmark. A small panel appears, top-right.
  3. Pick the design to copy from, and the product to put it onto.
  4. Tap Copy design →. The panel reports each step and confirms from the server.
The product it copies onto is overwritten. The source is only read. The target's thumbnail updates to the source's; open the target in the designer to see it render. Use a throwaway product until you trust it.

The tool loads fresh from this site each time you tap it, so it always runs the current version — nothing to reinstall when it changes.
